Token Radar

Pre-token protocols, priced by a model fitted on the market's own record — not by hand-set multiples.

An implied value is what a token would be worth if the protocol's record stayed as it is. The radar does not predict whether or when a token is issued, and it says a protocol records no token — DefiLlama's record is not proof that none exists. Bands are the fitted peer group's own residual interquartile range: wide where the market prices a group inconsistently.

The evidence the fit stands on

These protocols already trade, so the market has priced them. The model was fitted on the 128 traded protocols with a recorded market cap; below, the largest of them with the value the fitted model would have given each — the reader can check the fit against the record directly.
